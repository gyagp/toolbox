# Toolbox · 工具箱

Windows 小工具集合，使用 **C# / WinUI 3 / Windows App SDK** 构建。首批完整迁入 Moment（时刻 / Shike）的截图、长截图、录屏与内容库功能。

[下载最新版](https://github.com/gyagp/toolbox/releases/latest) · [开发说明](docs/architecture.md) · [迁移说明](docs/migration.md) · [验证与限制](docs/validation.md)

## 当前功能

启动后直接进入屏幕截图。侧栏按用途分成“屏幕与媒体”“文件与存储”“文档”“窗口与系统”四组，点击工具直接进入页面。

| 分组 | 工具 |
| --- | --- |
| 屏幕与媒体 | 屏幕捕获（页面顶部切换截图、长截图、录屏、内容库）、图片查看器 |
| 文件与存储 | 文件处理（移动、回收、彻底删除、占用查询）、磁盘清理（只读分析、Windows 审查入口与 Codex 旧版本整理） |
| 文档 | PDF 工具：预览、合并、拆分、删除页面、调整顺序、旋转及编辑 |
| 窗口与系统 | 关闭窗口：屏幕上高亮选择，确认后请求正常关闭 |

| 功能 | 状态 |

| PDF 页面管理 | 打开或合并多个 PDF，按范围拆分、删除页、上移/下移、旋转、撤销与重做；导出新文件 |

工具箱不上传截图、录屏或音频。当前没有联网服务、账号或自动更新功能。

## 运行

支持 **Windows 10 2004（build 19041）及以上、Windows 11，x64**。

1. 在 [GitHub Releases](https://github.com/gyagp/toolbox/releases/latest) 下载 `Toolbox-<版本>-win-x64.zip`，或从本地 `artifacts/` 取得打包文件。
2. 解压整个目录，运行 `Toolbox.exe`。请勿只移动 exe 文件。
3. 发布包包含 .NET、Windows App SDK 和 Visual C++ 运行库，无需单独安装这些运行时。

此工作目录也可双击 `start.bat`；优先启动 `artifacts/publish/Toolbox.exe`，没有发布包时使用 .NET 10 SDK 从源代码运行。

当前版本未做代码签名。Windows N / KN 版本需要系统的 Media Feature Pack 才能使用录屏和原生窗口捕获。当前不提供 ARM64 原生包或安装程序。

## 使用

**屏幕捕获**：点击侧栏“屏幕捕获”直接打开截图页面，通过顶部的“截图 / 长截图 / 录屏 / 内容库”切换功能；不弹出下拉菜单。原有快捷键不变。

**关闭窗口**：进入“窗口与系统 → 关闭窗口”，点击“选择窗口”。Toolbox 暂时隐藏，用桌面快照显示窗口位置；移动鼠标高亮，单击选中，`Esc` 或右键取消。返回后查看窗口标题、程序/PID 和屏幕预览，再点击“关闭所选窗口…”确认。确认窗口默认选中取消；底部操作按钮在小窗口中仍可访问。

发送的是一次普通 `WM_CLOSE`，不结束进程、不关闭同进程的其他窗口、不提权，也不确认原程序中的保存提示。未保存内容是否得到提示和保留由原程序决定。请求前重新核对 HWND、PID、进程创建时间、窗口标题和类名；窗口已改变、隐藏、最小化或无法核对时要求重新选择。桌面、任务栏、系统菜单、关键进程、Toolbox 自身及正在等待模态对话框的父窗口不能选择；前面的不可选窗口不会穿透到后面的窗口。

最多观察两秒：窗口消失才报告关闭，否则显示“已发送关闭请求，窗口仍在”，请检查保存提示或程序响应。取消等待不能撤回已经发出的请求，不自动重发或强制结束。屏幕快照只保存在内存，离开页面释放；多显示器、混合 DPI、热插拔和更高权限窗口仍需人工核对。极短时间内窗口被同进程销毁重建的竞态不能完全消除。

**PDF 工具**：进入“文档 → PDF 工具”，点击“打开”载入 PDF，“合并”追加其他文件。左侧可勾选多页，使用上下箭头调整顺序、旋转或删除；页码支持 `1-3,5`。所有变化先保存在内存，可撤销/重做；关闭有未导出修改的窗口会提示。

点击“拆分”，输入 `1-3;4-6;7` 等分组，或留空每页一个文件，结果放入新建子文件夹。点击“导出”，输入新文件名并选择输出目录。不会覆盖原件或已有文件。也可用 `Toolbox.exe "D:\example.pdf"` 直接打开。

编辑时选择“添加文字”或“批注文本框”，输入内容和字号，再在页面上拖出区域；选择“标记区域”或“安全遮盖”后直接框选。“本页编辑”可选择并修改新增文字，或删除标记。支持缩放、适应页面和适合宽度。批注为可见文本框，当前不修改 PDF 已有文字/图片，不提供 OCR。

**安全遮盖会把整个导出文件转为图像 PDF**，包括拆分结果，从而不保留原始可复制文字、隐藏内容流或附件。遮盖区域在渲染后再次涂黑，避免原注释盖在遮盖上方。输出不能搜索或复制文字，原件仍保留。普通未遮盖输出保留页面矢量内容；页面整理本身不等于安全脱敏。

当前 PDF 范围：不输入打开密码，不编辑带交互表单、数字签名或编辑权限限制的文件；页面副本不保留文档级书签和附件。单个输入最多 128 MiB，工作区合计 256 MiB/2000 页；安全图像化每份输出最多 200 页/128 MiB 图像数据，约 200 dpi、最长边最多 4096 像素。较大文档可按范围拆分。

**磁盘清理**：进入“文件与存储 → 磁盘清理”，选择磁盘，点击“只读扫描”。常规扫描只读取容量和文件元数据，不执行删除、移动、清空回收站或结束进程。扫描可取消；跳过链接、联接、云占位和无权限内容，达到扫描上限会明确标为不完整。Codex 旧程序包在下面的独立区域预览和确认，不属于通用缓存删除。

**Codex 旧版本**：在“Codex 旧版本”区域选择保留最新 1 个或 2 个版本（默认 2），点击“扫描旧版本”。一次扫描当前用户的 `%USERPROFILE%\.codex\packages\standalone\releases` 和 `%USERPROFILE%\.codex\packages\app-server-daemon\releases`，不跟随重定向的安装目录；按版本号而非时间或文件名排序，各安装、每种架构独立保留。预览列出每个包的来源、大小及保留原因；某个安装无法安全核对时跳过并说明，另一个独立核对。再点击“删除旧版本…”，在简短确认框中点击“删除”即可，无需输入文字。**永久删除，不经过回收站**；大小为逻辑大小，硬链接、压缩等会影响实际释放量。

`current` 启动器目标、`auto-update-version` 指向及被 Codex/辅助进程使用的版本会额外保留，因此可能超过 1–2 个。仅处理布局版本 1 且清单与目录名称一致的完整 Windows 稳定版程序包；未知、预发布、不完整、带额外顶层内容、链接/联接、脱机/云占位或不可核对的包保留并说明。运行进程检查不完整时禁用删除。更新锁被占用时停止；不结束进程、不提权、不清空回收站，不碰配置、登录、会话或项目。即使版本在预览后开始运行，也会再次检查并由 Windows 映像删除保护拦截。

执行前逐包重读保留策略、启动指向、进程和文件清单；内容变化的包跳过，不会把新出现的候选包加入已确认计划。固定安装祖先、启动链接、元数据与包文件的句柄，使用句柄删除，不做基于任意路径的递归删除。取消按钮始终可见；取消或失败可能留下部分已处理结果，已完成的删除不回滚，请重新扫描查看记录。没有自动或定时清理；后续升级后可再次扫描。

结果是**占用估算，不是安全可删列表或可释放空间**。仅检查当前用户临时目录、DirectX 缓存、缩略图缓存、Windows 错误报告、Windows 临时目录、更新下载目录及回收站；不遍历个人文档、下载、照片、项目或整个 AppData，不按扩展名或文件年龄推断可删。

点击“打开 Windows 磁盘清理…”后，由 Windows 列出类别并等待你确认。Toolbox 只传入所选盘符，不勾选类别、不提权、不使用无人值守清理参数；也可以打开“Windows 存储设置”，自行核对其中显示的磁盘。**请保留不确定的项目**：临时文件可能是未保存工作或恢复数据，回收站可能需要恢复，旧 Windows 安装可能仍用于回退。不会启用“存储感知”或自动清理；完成后返回重新扫描。此工具不承诺 Windows 中任意类别都适合删除。

**图片查看器**：点击“屏幕与媒体 → 图片查看器”，选择或拖入一张图片。GIF 默认自动播放，可点击“暂停 GIF / 播放 GIF”控制。支持 Ctrl + 滚轮、加减按钮、适应窗口和原始大小；上一张/下一张按资源管理器的数字顺序浏览同目录图片（1、2、10）。损坏图片会显示错误，仍可继续翻到下一张。离开页面会释放图片文件句柄，返回时重新打开。WebP 等扩展格式依赖当前 Windows 的图像解码器；多页 TIFF 当前显示第一页，不提供逐页切换。

**全屏看图**：点击“全屏 F11”、按 F11 或双击图片进入，隐藏窗口边框、侧栏和工具栏。`← / →` 或 `PageUp / PageDown` 翻图，`Home / End` 跳至首尾，空格控制 GIF。移动鼠标显示浮动按钮，静止后自动隐藏。按 `Esc`、F11、双击图片或点击“退出全屏”返回原窗口大小。

**关联图片格式**：先把完整便携包放在固定目录。右键图片 →“打开方式”→ 选择 `Toolbox.exe`，即可直接打开图片并浏览同目录图片。也可在看图器点击“关联图片格式…”，将 Toolbox 添加到 Windows 打开方式和默认应用列表，再由你选择要关联的扩展名。此按钮只注册当前用户的候选应用，不自动修改默认程序；应用目录移动后再次点击即可更新路径。

命令行同样支持图片路径，路径含空格时加引号：

```powershell
./Toolbox.exe "D:\Photos\旅行照片\2 图片.jpg"
./Toolbox.exe --fullscreen "D:\Photos\旅行照片\2 图片.jpg"
```

**文件处理**：在“文件与存储 → 文件处理”粘贴绝对路径，或点击“选择”挑选文件/文件夹。移动需要目标文件夹，删除默认进入 Windows 回收站。执行前会显示源路径和操作确认。

**自动处理占用**：默认勾选“遇到占用时自动结束相关进程并重试”。Windows 明确报告来源文件被占用后，Toolbox 查询占用者，结束前再次核对源路径范围、当前占用以及 PID/创建时间，然后重试已确认的同一操作，最多两轮；处理记录会显示结束或跳过的进程及原因。相关程序未保存的工作可能丢失。权限不足、目标冲突或目标占用不会触发自动结束；系统关键进程、服务、其他会话、身份不明进程和 Toolbox 自身会跳过。不自动提权，不按进程树批量结束；取消后不会继续结束进程或重试，也不会恢复已经结束的进程。取消勾选后保留手动选择和确认流程。设置仅适用于文件处理；常规磁盘扫描只读，Codex 旧版本整理也不会结束进程。

**彻底删除**：点击独立的“彻底删除…”按钮，在确认窗口核对完整路径并输入文件或文件夹的名称，随后点击“彻底删除”。默认按钮为“取消”。此操作包含文件夹内全部内容，不进入回收站，无法通过回收站或 Toolbox 恢复；不提供数据覆写或安全擦除保证。一次确认包含开启自动处理时的两轮自动重试；自动重试保持原删除模式，不会把回收升级为彻底删除。手动点击“重试彻底删除…”需要重新输入名称确认；手动“结束选中进程并重试…”也会在结束进程前再次确认删除。文件夹失败时可能已删除部分内容，请先核对剩余文件。

**取消与关闭**：移动、移入回收站和彻底删除期间，页面底部始终显示“取消操作”；查询占用时显示“取消查询”。取消通过 Windows 操作回调停止后续处理，可能需要等待当前步骤返回；已经完成的移动或删除不会回滚。点击窗口关闭按钮会请求取消并等待当前任务结束，然后自动关闭。取消后清除待重试操作，请核对源、目标或回收站中的内容，再决定下一步。

**操作进度**：底部固定区域显示当前阶段、正在处理的路径和已用时间。Windows 提供有效总工作量时显示“约 XX%”；总量未知时显示“统计中”和流动进度条，不凭时间推算比例。Windows 可能更新估算总量，比例也会调整；它不是精确的文件数或字节数。查找占用、结束进程、自动重试和取消时会切换阶段并清除原百分比。只有操作返回成功并核对结果后才显示 100%；很快的同盘移动可能直接显示完成。路径太长时可悬停查看完整内容。

自动处理后仍然失败，或关闭自动处理时，列表显示剩余占用者，默认不勾选。可自行关闭相关程序，或勾选进程点击“结束选中进程并重试”并确认。手动结束失败时显示原因、不继续文件操作；不自动提权。手动发起重试后仍按上方开关决定是否自动处理新占用。

占用查询结合 Windows Restart Manager 和文件系统的目录句柄查询，空文件夹以及终端当前工作目录也会检查。例如 `cmd.exe` 正停留在待移动目录时，可以先执行 `cd /d D:\` 或关闭该窗口，再重试，无需强制结束。查询不能覆盖所有驱动、远程文件系统或受保护进程，无结果不代表文件一定可移动。扫描跳过链接/重解析点并报告无法访问的路径。跨磁盘移动若部分失败，请先核对源、目标内容；不会自动合并已有目标。内容库“最近删除”与 Windows 回收站独立。

| 结束当前长截图或录屏并保存 | `Ctrl + Shift + F` |
| 取消框选 | `Esc` |

**截图**：点击“新建截图”或使用快捷键，顶部工具栏提供与 Windows 截图工具相似的四种模式。矩形与任意形状以进入截图时的画面为准；全屏包含所有显示器；窗口模式在点击后捕获所选窗口的当前画面。`Esc` 取消。结果保存为 PNG，可预览、复制图片或打开所在目录。“长截图 / 录屏显示器”不限制普通截图的范围，只决定其工具栏初始所在屏幕。

**滚动截图**：只框选同一个窗口内的滚动内容（至少 80 × 160 像素），排除浏览器工具栏、固定标题和悬浮控件。工具箱会聚焦目标窗口，将鼠标放入区域中并自动滚动、等待画面稳定、拼接。无需你操作滚轮，点击浮动条的“结束并保存”或按 `Ctrl + Shift + F` 即可停止。到达底部或连续三次无法继续滚动时自动保存；焦点切换、鼠标离开区域、窗口移动、画面不稳定、匹配失败或大小达到上限时，停止滚动并保存已成功捕获的部分，同时提示原因。上限为 30,000 像素高及 256 MiB 原始拼接数据。请检查保存结果；固定元素、动画、重复纹理、跳页式滚动及更高权限窗口仍可能无法捕获。

**录屏**：先确认显示器和音频选项，点击开始。浮动条可以停止；从任务栏回到主窗口可以暂停、继续。浮动条通过 Windows 捕获排除 API 隐藏。视频完成编码后才会从 `.partial.mp4` 重命名为 `.mp4`。异常退出可能留下未完成的视频。

**内容库**：点击侧栏“捕获内容库”，即可浏览系统“图片/Shike”和“视频/Shike”中的所有 PNG 和已完成的 MP4（包括旧版本生成的内容）。支持全部、图片、视频、最近删除筛选，以及名称搜索、时间/名称/大小排序。选中图片后可用 Ctrl + 滚轮缩放或点击“适应”；视频可在软件内播放，默认不自动播放。完成捕获后自动打开内容库并选中新文件。外部新增、重命名、删除文件也会刷新显示。

**删除与恢复**：移至“最近删除”会将文件保留在原保存目录的 `.shike-trash` 内，重启后仍可恢复，不会自动清空。恢复遇到同名文件会拒绝覆盖；请先重命名已有文件。只有在“最近删除”中再次确认“永久删除”才会实际释放该文件的空间。重命名不改变扩展名，内容库不会操作保存目录外的文件或链接文件。

## 开发

需要 Windows、.NET 10 SDK。Visual Studio 可选；打包时需要 Visual Studio C++ Build Tools 的 x64 可再发行运行库文件。

```powershell
dotnet restore src/Toolbox.App/Toolbox.App.csproj
dotnet build src/Toolbox.App/Toolbox.App.csproj -c Release -p:Platform=x64
dotnet run --project src/Toolbox.App -c Release -p:Platform=x64
dotnet run --project tests/Toolbox.Core.Tests -c Release
dotnet run --project tests/Toolbox.Platform.Tests -c Release
```

打包：

```powershell
pwsh ./scripts/package.ps1 -Version 0.1.5
```

输出 ZIP 与 SHA-256 文件位于 `artifacts/`。推送 `v*` 标签会运行 GitHub Actions，执行核心与 Windows 文件工具测试、构建并上传 GitHub Release 附件。若已手工发布经本地验证的附件，CI 保留已有 Release。
