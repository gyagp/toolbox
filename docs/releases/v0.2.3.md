# Toolbox v0.2.3

磁盘清理新增“Codex 旧版本”区域，扫描当前用户 `.codex/packages/standalone/releases`，选择保留最新 1 或 2 个版本（默认 2），预览后输入“删除”确认永久移除旧程序包。

自动保护 current 启动目标、自动更新指向与运行版本；无法完整核对的包保留并说明，因此可能超过保留数量。按架构分别保留稳定版本，不按文件日期推测。更新锁、运行检查、包内容变化和链接保护贯穿执行；不结束进程、不提权，不触碰配置、登录、会话或项目。

支持进度、处理记录、固定可见的取消按钮和关闭窗口时先取消。取消不回滚已完成的删除。常规磁盘扫描仍为只读，Windows 清理仍由用户在系统界面审查。

31 项 Codex 专项检查及确认/取消/关闭窗口界面诊断通过；测试仅删除自己生成的隔离包。真实 Codex 安装仅执行只读预览，没有代替用户删除。

下载 `Toolbox-0.2.3-win-x64.zip` 并完整解压，运行 `Toolbox.exe`。Windows 10 2004 及以上 / Windows 11，x64；含运行库，未做代码签名。
