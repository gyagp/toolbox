# Toolbox v0.2.2

新增“窗口与系统 → 关闭窗口”：在屏幕上高亮选择要关闭的窗口，再查看标题、进程/PID 和预览并确认。Esc 或右键取消选择，确认窗口默认取消，小窗口中的关闭/取消按钮固定在底部。

仅向所选窗口发送一次正常关闭请求，不强制结束进程，不处理程序自己的保存提示。窗口仍存在时明确提示检查保存对话框或程序响应；取消等待不能撤回已发送的请求。

请求前重新核对窗口和进程身份；桌面、任务栏、系统关键进程、Toolbox 自身与身份不明的窗口不可选。

Core 76 项、Windows 173 项检查及窗口工具界面诊断通过。正常关闭请求是否保护未保存的工作由原程序决定；混合 DPI、多显示器和更高权限窗口仍需人工核对。

下载 `Toolbox-0.2.2-win-x64.zip` 并完整解压，运行 `Toolbox.exe`。包含 .NET、Windows App SDK 和 Visual C++ 运行库。Windows 10 2004 及以上 / Windows 11，x64；未做代码签名。
