# Toolbox v0.2.4

Codex 旧版本清理现在一次扫描 `standalone/releases` 和 `app-server-daemon/releases`。各安装、每种架构独立保留最新 1–2 个版本（默认 2）；预览、进度和处理记录标明包的来源。

删除改为简单的一次确认，不再要求输入“删除”。确认框只显示待删数量、大小和永久删除说明，点击“删除”即可继续，默认选中取消。

仍需先扫描预览；各自的最新版本、current、自动更新指向、运行进程、安装锁和包完整性保护保持原有行为。取消按钮和关闭窗口时的取消流程保留。某个安装无法安全核对时跳过并说明。

45 项 Codex 专项检查、Release 构建及打包后的启动/磁盘清理界面诊断通过；真实 Codex 安装只读检查，未执行删除。

完整解压 `Toolbox-0.2.4-win-x64.zip` 后运行 `Toolbox.exe`。Windows 10 2004 及以上 / Windows 11，x64；含运行库，未做代码签名。
