Toolbox v0.1.3 · 工具总览、文件处理与图片查看器

- 完整迁入 Moment / 时刻的截图、自动长截图、录屏和内容库；兼容已有捕获文件和最近删除。
- 按用途分组，提供紧凑的工具总览及独立工具页。
- 文件/文件夹移动与回收站删除；查找占用进程，由用户勾选并确认后结束，再重试操作。
- 修复空文件夹、终端当前工作目录的占用遗漏；错误详情保留 Windows 原生错误码。
- 新增图片查看器：PNG、JPEG、GIF、BMP、TIFF、WebP；缩放、适应窗口、同目录浏览；GIF 自动播放、暂停和继续。

下载 `Toolbox-0.1.3-win-x64.zip`，完整解压后运行 `Toolbox.exe`。包含 .NET、Windows App SDK 与 Visual C++ 运行库。支持 Windows 10 2004+ / Windows 11 x64，附 SHA-256 校验文件；尚未签名。

WebP 等扩展格式依赖系统解码器。目录占用查询不能覆盖所有远程文件系统、驱动和受保护进程。自动长截图仍为实验功能；完整屏幕捕获回归有已记录的滚动拼接失败。验证详情见 `docs/validation.md`。
