Toolbox v0.1.5 · 全屏看图与图片关联

- 原生全屏看图：F11/双击切换，Esc 退出并恢复原窗口，隐藏侧栏和工具栏。
- 方向键、PageUp/PageDown、Home/End 连续浏览；按资源管理器的数字顺序排列，损坏图片也可继续跳过。
- 全屏下保持 GIF 动画，并提供自动隐藏的浮动翻图、暂停和退出按钮。
- 支持从“打开方式”或命令行直接打开图片，支持含空格与中文的路径和可选 `--fullscreen`。
- 新增“关联图片格式…”入口，注册当前用户的候选应用并打开 Windows 默认应用设置，由用户选择默认关联。

下载 `Toolbox-0.1.5-win-x64.zip`，完整解压到固定目录后运行 `Toolbox.exe`。包含运行库，附 SHA-256。支持 Windows 10 2004+ / Windows 11 x64；尚未签名。已知捕获和系统解码器限制见 `docs/validation.md`。
