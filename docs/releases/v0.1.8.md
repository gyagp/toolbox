# Toolbox v0.1.8

文件处理默认启用“遇到占用时自动结束相关进程并重试”，适用于移动、移入回收站和彻底删除。

- Windows 明确报告来源被占用后，重新核对相关文件/目录与进程身份，再自动结束占用者并重试原操作，最多两轮。
- 处理记录显示进程名称、PID、跳过原因与重试次数；可取消勾选，恢复手动处理。
- 跳过系统关键进程、服务、其他会话、身份不明的进程和 Toolbox 自身。不按进程树批量结束，也不自动提权。
- 权限不足、目标重名或目标占用不会触发自动结束；部分移动已产生目标冲突时停止自动处理。
- 保留取消与关闭窗口时的取消流程，取消后停止后续结束和重试。相关程序未保存的工作可能丢失，已结束进程不会恢复。

彻底删除仍需首次输入名称确认，自动重试不改变删除模式。磁盘清理仍保持只读。完整滚动捕获的历史拼接限制未在本版本解决。
