# Toolbox v0.2.0

截图、长截图、录屏和捕获内容库集中到“屏幕捕获”菜单，原有快捷键保持不变。

新增“文档 → PDF 工具”：

- 本地预览、缩放、合并、按页码分组拆分、删除页面、上下调整顺序和旋转。
- 框选添加中文/英文文字、可见批注文本框、标记和安全遮盖；可修改新增文字、删除标记、撤销/重做。
- 导出新文件，不覆盖原件或已有输出；未导出修改在关闭时提示。
- 安全遮盖输出全文图像化，不保留可复制原文或原始内容对象；输出不能搜索/复制文字，原件保留。
- 支持 PDF 文件路径启动，内置 OFL 中文字体，无需联网处理或安装额外阅读器。

不提供已有文字/图片改写或 OCR；密码、编辑权限受限、交互表单和数字签名文件不在当前编辑范围内。单输入 128 MiB、工作区 256 MiB/2000 页，安全图像化每份输出最多 200 页。

原有文件处理、图片查看器和只读磁盘清理保留。滚动捕获的历史拼接限制未在本版本解决。
