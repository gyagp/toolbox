# Toolbox v0.1.7

修复文件操作没有取消入口、处理期间无法关闭窗口的问题，并加入适用于文件和文件夹的“彻底删除…”选项。

- 显示完整路径，要求输入项目名称，默认选择取消。
- 直接删除，不进入回收站，无法通过回收站或 Toolbox 恢复。不提供数据安全擦除保证。
- 删除失败后自动检查占用，重试仍需重新确认；结束选中进程后重试，也会先确认删除。
- 目录删除可能部分完成，失败提示明确说明已删除内容不能回滚。
- 保留普通“移入回收站”；磁盘清理工具继续只读。
- 移动、回收和彻底删除新增固定在底部的取消按钮；关闭窗口会请求取消，等待 Windows 停止当前步骤后自动关闭。
- 取消不会回滚已完成的文件操作，也不会继续查锁或自动重试；请核对源与目标。

验证包括文件、空目录、多层目录、占用与重试、目录联接目标保留，以及名称确认和取消。完整滚动捕获自检的原有拼接限制未在本版本解决。
