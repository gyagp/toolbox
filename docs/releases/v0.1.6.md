# Toolbox v0.1.6

新增“文件与存储 → 磁盘清理”，以只读分析和人工审查为默认安全边界。

- 查看本地磁盘容量，只读统计已知缓存位置和回收站，显示大小、范围和注意事项。
- 本工具不删除或移动文件、不清空回收站、不结束进程，不按文件年龄或扩展名判定可删。
- 跳过目录联接、链接、云占位和权限受限位置，支持取消，明确显示不完整结果。
- 打开 Windows 原生磁盘清理或存储设置；由你审查类别并确认，不启用自动清理或无人值守参数。

占用估算不等于可释放空间。Windows 中不确定的项目请保留，尤其是下载、回收站、恢复数据与用于回退的旧安装。

此安全设计仅适用于新磁盘清理工具；现有手动文件处理与捕获内容库功能保留各自的确认流程。完整捕获自检在滚动拼接环节的已知限制未在本版本解决。
