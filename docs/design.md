# Toolbox 界面设计

目标：紧凑、现代、清晰的 Windows 原生小工具集合。

- 默认窗口 1240 × 860 物理像素，受当前屏幕工作区约束；侧栏 188 逻辑像素。
- 深绿色侧栏、浅灰绿工作区、白色工具卡片；统一细边框、圆角、字号、间距与线性图标。
- “工具总览”按“屏幕与媒体”“文件与存储”分组展示入口；宽度不足时卡片从两列变成一列。
- 截图、长截图、录屏各有独立操作页；只显示当前工具相关的设置。
- 文件处理将路径选择与操作放在一张紧凑卡片中，占用结果在另一张卡片里显示；默认不选择进程，强制结束前再次确认。
- 文件操作提供移动、移入回收站和独立的红色“彻底删除…”入口。彻底删除显示完整路径，要求输入名称，默认取消；重试明确标为“重试彻底删除…”并重新确认。失败后自动查询占用并滚动到结果，不设置单独的查找按钮。
- 文件操作期间固定底部取消条，始终保留按钮空间；关闭窗口会先取消再关闭。取消后的提示说明已完成步骤不会回滚，清除待重试动作。
- 文件处理默认勾选自动结束占用者并重试，紧邻开关说明未保存工作风险。处理记录列出进程名称、PID、跳过原因和重试次数；自动流程结束后保留剩余占用者供手动处理。开关在操作中禁用，取消按钮始终可用。
- 底部进度区显示阶段、约百分比、当前路径、进度条和已用时间；长路径省略显示并提供完整路径提示。未知总量和非传输阶段显示不确定进度，不留下旧百分比；窄窗口仍为取消按钮保留固定空间。
- 磁盘清理独立为只读分析页，分为容量、Windows 审查入口、占用参考。没有一键删除、可释放空间承诺或默认勾选。侧栏可滚动，并把当前工具滚入可视区域。
- 图片查看器采用独立画布，前后浏览、缩放和 GIF 控制分行排列；紧凑窗口也能直接看见 GIF 播放按钮。小窗口收起侧栏快捷键提示，为工具入口留出空间。
- 全屏看图使用深色背景并隐藏主导航，浮动翻图、GIF 和退出按钮在鼠标静止后收起；提供 F11、Esc、方向键等键盘操作。图片关联入口交给 Windows 默认应用设置完成选择。
- 内容库保留网格缩略图和预览，不自动播放视频。
- 首页与侧栏使用同一个 ToolCatalog，避免新增工具后出现入口不一致。
- 截图、长截图、录屏、捕获内容库合并到“屏幕捕获”菜单；首页只保留一个集中入口。图片查看器仍有独立入口。
- PDF 工具采用左侧页面列表、右侧预览画布和顶部命令栏。编辑模式以框选区域添加文字、批注、标记和安全遮盖；长文件名省略，预览支持缩放和适合宽度。未导出修改在关闭时提示；含遮盖的导出明确说明输出图像化。
- WinUI 原生控件负责键盘、焦点、悬停和滚动交互；图标使用系统字体与几何路径，不使用图片模拟控件。

本次设计未调用 Google 图片 API，也未读取 GOOGLE_API_KEY。工具箱应用图标由 scripts/generate-icon.py 生成多尺寸 ICO，无外部图片依赖。

使用应用自己的 RenderTargetBitmap 检查真实控件渲染。--library-test 会输出首页、各工具页、占用结果和内容库截图；未以设计稿代替运行验证。
