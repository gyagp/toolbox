# Toolbox 界面设计

目标：紧凑、现代、清晰的 Windows 原生小工具集合。

- 默认窗口 1240 × 860 物理像素，受当前屏幕工作区约束；侧栏 188 逻辑像素。
- 深绿色侧栏、浅灰绿工作区、白色工具卡片；统一细边框、圆角、字号、间距与线性图标。
- “工具总览”按“屏幕与媒体”“文件与存储”分组展示入口；宽度不足时卡片从两列变成一列。
- 截图、长截图、录屏各有独立操作页；只显示当前工具相关的设置。
- 文件处理将路径选择与操作放在一张紧凑卡片中，占用结果在另一张卡片里显示；默认不选择进程，强制结束前再次确认。
- 文件操作只提供移动和回收站删除入口；失败后自动查询占用并滚动到结果，重试失败会再次查询，不设置单独的查找按钮。
- 图片查看器采用独立画布，前后浏览、缩放和 GIF 控制分行排列；紧凑窗口也能直接看见 GIF 播放按钮。小窗口收起侧栏快捷键提示，为工具入口留出空间。
- 内容库保留网格缩略图和预览，不自动播放视频。
- 首页与侧栏使用同一个 ToolCatalog，避免新增工具后出现入口不一致。
- WinUI 原生控件负责键盘、焦点、悬停和滚动交互；图标使用系统字体与几何路径，不使用图片模拟控件。

本次设计未调用 Google 图片 API，也未读取 GOOGLE_API_KEY。工具箱应用图标由 scripts/generate-icon.py 生成多尺寸 ICO，无外部图片依赖。

使用应用自己的 RenderTargetBitmap 检查真实控件渲染。--library-test 会输出首页、各工具页、占用结果和内容库截图；未以设计稿代替运行验证。
